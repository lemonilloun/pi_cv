# open_clip_torch shared with monitoring:
#   python3 -m pip install -r server/requirements-server-cv.txt -r server/requirements-scene3d.txt

# "remote") — pycolmap/torchvision/certifi below are now only exercised by
# the explicit "colmap_dav2"/"local" fallback paths, not the default run.
# Not removed: torch/open_clip_torch (requirements-server-cv.txt) are still
# genuinely needed locally regardless, for cv_worker.py's live depth view
# and monitoring/'s MobileCLIP re-id — unrelated to scene3d.
